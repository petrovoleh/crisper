# Crisper — AI Fridge & Zero-Waste Recipes (Android)

**Crisper** (*«Готуй з того, що є. Без зайвого.»*) — Android-аналог і розвиток концепції Pantryx у фірмовій дизайн-системі **Warm Culinary Editorial** (зі світлою та темною темами).

## Реалізований функціонал
- **Холодильник (`Fridge Inventory`)**: трекінг термінів придатності («Використати скоро»), пошук, фільтри зон зберігання, візуальна «Шухляда свіжості» та полиці холодильника, швидке додавання й редагування.
- **AI Сканер Кухні (`AiScannerSheet`)**: розпізнавання фото полиці холодильника, чека з магазину та пошук штрих-кодів через **Open Food Facts API** + інтеграція **Gemini 2.5 Flash Vision**.
- **Розумний підбір рецептів (`Recipes Matcher`)**: автоматичний розрахунок `% збігу` з наявними продуктами, підказки замін від AI-сушефа, закладки, фільтри та генератор авторських рецептів під залишки.
- **Імпорт із соцмереж (`SocialImportSheet` + Android `ACTION_SEND`)**: прийом посилань із TikTok, Instagram Reels, YouTube, Threads та кулінарних сайтів напряму через системне меню «Поділитися».
- **Режим Готування (`Cooking Mode Hub`)**: утримання екрана увімкненим (`FLAG_KEEP_SCREEN_ON`), динамічний перерахунок грамажу на `1 / 2 / 4` порції, покроковий фокус-режим, живий кухонний таймер та авто-списання використаних продуктів після завершення.
- **Кулінарний Баланс & Планувальник (`Zero Waste Balance` + `WeeklyMealPlannerSheet`)**: Zero-Waste індекс, збережений бюджет у `₴`, зниження `CO₂`, журнал врятованих продуктів, розумний список покупок із перенесенням купленого в холодильник та 7-денний планувальник меню.
